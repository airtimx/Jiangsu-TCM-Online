## Background

项目介绍一期要求：**官网展示** — 在 Web 浏览器浏览平台已发布内容；**在线学习与评测仅在小程序**。官网作为公众入口与 SEO 渠道，与小程序形成「浏览在 Web、学习在小程序」的分工。

## Scope

**In scope（一期）**
- Nuxt 3 + Vue 3 官网工程（SSR/SSG，SEO 友好）
- 站点首页、资讯列表/详情、专题列表/详情（只读预览）
- 课程/图书/播客/直播等内容卡片列表与详情摘要（不含播放/阅读器）
- 统一顶栏：Logo、导航、小程序码 / 打开小程序 CTA
- 后端 `/api/web/v1/*` 公开读接口（聚合 03/08 等已审核内容）
- 站点配置：导航菜单、页脚、备案信息（`site_config`）
- 响应式布局（PC 优先，兼容平板/手机浏览）

**Out of scope（一期，二期「官网全功能升级」）**
- Web 端登录、学员认证、收藏、学习进度上报
- Web 端视频/音频播放、电子书阅读器、在线答题
- 专家答疑提交、知识库全文检索（Web）
- 与管理端相同的 CMS 能力

## Acceptance Criteria

- [ ] 未登录可访问首页、资讯、专题及内容列表/详情
- [ ] 仅展示 **审核通过** 且 **对 Web 开放** 的内容（字段 `web_visible=1`）
- [ ] 学习/考试相关按钮统一引导至小程序（二维码 + scheme 链接）
- [ ] 资讯详情支持富文本安全渲染（XSS 过滤与 03 一致）
- [ ] Lighthouse SEO：首页可索引，核心列表页有 `title`/`description`
- [ ] `/api/web/v1/*` 无 JWT；接口限流 + CDN 缓存头约定文档化
- [ ] 与 03 管理端配置的首页 Banner/分类在 5 分钟内同步（或清 CDN 后可见）
