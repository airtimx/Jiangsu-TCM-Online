## 1. 项目背景与目标

### 1.1 背景

江苏省中医培训需要统一的线上知识服务与培训管理平台，整合全省中医专家、资讯与课程资源，实现「平台上移、服务下延」，通过微信小程序将知识服务直达基层培训人员。

### 1.2 建设目标

- **管理提效**：统一后台管理资讯、课程、图书、专题、学员、考核与统计
- **学习闭环**：资讯浏览 → 专题学习 → 学时追踪 → 在线测评 → 学分/成绩统计
- **专家服务**：认证学员可向专家一对一提问，问答可公开展示
- **多端协同**：小程序为主学习端；管理端 Web；**官网一期以内容展示为主**（学习/测评在小程序）

### 1.3 平台构成

| 端 | 形态 | 一期能力 | 二期扩展 |
|---|---|---|---|
| 用户端 | 微信小程序 | 学习、测评、咨询、知识库 | 版本控制、直播深化 |
| 管理端 | Web 浏览器 | 全模块 CMS + RBAC + 统计 | 报表增强、活动管理 |
| 官网 | Web 浏览器 | 资讯/专题/内容浏览、SEO、引导小程序 | 全功能升级（学习/考试/Web 登录） |
| 外部 | 健康通 APP | — | 用户与内容共享 |

## 2. 用户角色

| 角色 | 描述 | 主要端 |

| 微信访客 | 授权登录，未认证 | 小程序 |

| 系统管理员 | 管理员、角色、权限配置 | 管理端 |
| 数据分析员 | 查看学时、学员、地区、成绩统计 | 管理端 |

### 3.3 项目介绍 — 一期补充能力

- 电子书：PDF/EPUB 在线阅读、书签
- 学习统计：学习次数、时长、积分
- 直播：接入第三方直播
- 考卷：动态组卷、随机抽题
- 知识库：书籍切片、章节自动生成、配题考核
- **官网展示**（16-official-web）：Web 浏览已发布资讯/专题/内容摘要，学习测评引导至小程序

### 3.4 官网 — 一期（16-official-web）

| 能力 | 说明 |
|---|---|
| 首页与导航 | Banner、分类入口、备案信息 |
| 资讯 | 列表、详情、富文本（与 03 同源） |
| 专题与内容卡片 | 专题详情只读；课程/图书/播客/直播摘要 |
| 小程序引导 | 二维码 + scheme，不提供 Web 端播放/答题 |

### 3.5 二期范围

- 无纸化考核独立系统（Web + 移动端）

- 小程序版本控制
- 网络投票、问卷调查
- 直播录屏、PPT 场景
- 管理端报表下载增强
- 健康通 APP 对接
- 可视化大屏

| 审核 | 课程、图书、资讯、播客、直播、专题均需审核流 |

## 5. 核心业务流程

### 5.1 学员学习闭环

```
微信登录 → 学员认证 → 浏览首页/专题 → 学习视频/音频/图书
→ 记录学时 → 达到专题要求 → 参加考核 → 自动判分 → 统计入库
```

### 5.2 内容发布闭环

```
编辑创建内容 → 提交审核 → 审核员通过/驳回 → 配置到首页/专题
→ 小程序展示 → 用户学习/收藏/分享
```

### 5.3 专家答疑闭环

```
学员选择专家 → 提交问题 → 专家/管理员回复 → 公开展示问答记录 → 后台统计
```

## 6. 验收标准

### 6.1 用户端

- [ ] 微信授权登录与首次自动注册
- [ ] 学员认证通过后解锁专题学习与考核
- [ ] 资讯列表/详情/收藏/分享/搜索可用
- [ ] 专题内图书、视频、音频均可学习并记录进度
- [ ] 考核支持单选、多选、填空，提交后自动判分
- [ ] 专家咨询可按分类发起并查看回复
- [ ] 知识库按分类浏览与检索

### 6.2 管理端

- [ ] 登录后按角色展示菜单；记住账号可选
- [ ] 用户/学员 CRUD；学员批量导入导出
- [ ] 管理员、角色、权限完整 RBAC
- [ ] 首页分类与内容可配置并反映到小程序
- [ ] 课程/图书/资讯/播客/直播/专题全流程（含审核）
- [ ] 专题可绑定多种资源与指定学员
- [ ] 题库维护与考卷关联
- [ ] 学时/学员/地区/成绩四类统计可筛选
- [ ] 答疑与反馈可管理

### 6.3 官网（一期展示）

- [ ] 未登录可浏览首页、资讯、专题及内容列表/详情
- [ ] 不提供 Web 端学习播放与在线考试入口
- [ ] 「开始学习/参加考试」统一跳转小程序
- [ ] 仅展示审核通过且 `web_visible` 的内容
