# UI Prototypes — 江苏中医在线平台（高保真界面说明）

> 本文档按**管理端 / 小程序 / 官网**三端，还原使用手册中的界面结构，供 UI 设计与前端实现对齐。  
> 官网一期为**内容展示 + 引导小程序**（详见 `16-official-web`）。
> 色彩与品牌：主色建议 `#2E7D6B`（中医绿），辅色 `#C9A063`（金色点缀），背景 `#F5F7FA`。

---

## 1. 设计规范

### 1.1 栅格与尺寸

| 端 | 画布 | 栅格 | 备注 |
|---|---|---|---|
| 管理端 | 1440 × 900 基准 | 24 列，间距 16px | 左侧导航 220px 固定 |
| 小程序 | 375 × 812 基准 | 左右边距 16px | 安全区适配 iPhone |
| 官网 | 1280 × 800 基准 | 12 列，间距 24px | 顶栏 64px；最大内容宽 1200px |

### 1.2 组件库映射

| 端 | 组件库 |
|---|---|
| 管理端 | Element Plus |
| 小程序 | 原生 + uView / Vant Weapp |
| 官网 | Nuxt 3 + Tailwind |

### 1.3 通用交互

- 列表：分页 20 条/页，支持关键词搜索 + 高级筛选
- 表单：必填红星；保存 / 取消；危险操作二次确认
- 审核：状态 Tag（草稿/待审/已通过/已驳回）
- 空态：插画 + 引导文案

## 4. 官网高保真（一期展示）

### 4.1 站点首页

```
┌─────────────────────────────────────────────────────────────┐
│ [Logo] 首页 资讯 专题 课程 图书 直播 关于    [打开小程序]     │
├─────────────────────────────────────────────────────────────┤
│  [ Banner 轮播 — 与 03 配置同步 ]                             │
├─────────────────────────────────────────────────────────────┤
│  最新资讯          │  推荐专题                                │
│  ┌────┐ 标题...   │  ┌────┐ 专题名...                       │
│  └────┘           │  └────┘                                │
├─────────────────────────────────────────────────────────────┤
│  页脚：主办单位 | 备案号 | 客服电话                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 资讯详情

- 标题、分类、发布时间、来源
- 富文本正文（安全 HTML）
- 侧栏或底部：**打开小程序继续学习**（二维码 + 按钮）
- 无收藏/分享（一期；二期可开 Web 登录后收藏）

### 4.3 专题详情（只读）

- 专题封面、简介、学习要求说明（只读展示）
- 资源清单 Tab：资讯 / 课程 / 图书 / 音频（卡片，无播放）
- 固定 CTA：「请在小程序中开始学习与考核」

### 4.4 交互约束

| 操作 | 官网一期 | 小程序 |
|---|---|---|
| 浏览资讯/专题 | ✓ | ✓ |
| 视频/音频播放 | ✗ | ✓ |
| 电子书阅读 | ✗ | ✓ |
| 在线考试 | ✗ | ✓ |
| 专家提问 | ✗ | ✓ |
